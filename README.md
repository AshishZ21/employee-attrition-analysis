# Employee Attrition Analysis

## Project Overview
This project analyzes employee attrition to understand workforce trends and identify factors associated with employees leaving an organization.

## Objectives
- Analyze overall employee attrition.
- Explore attrition across departments and job roles.
- Examine workforce patterns using data analytics.
- Present findings through an interactive Power BI dashboard.

## Tools & Technologies
- Python — data cleaning and exploratory data analysis
- Pandas — data manipulation
- SQL — workforce data analysis
- Power BI — dashboard development
- Jupyter Notebook — analysis workflow

## Project Files
- `Data Analyst Project.ipynb` — Python analysis and data cleaning
- `Hr Analytics.sql` — SQL analysis queries
- `Hr_Analytics_backup.pbix` — Power BI dashboard
- `HR_Analytics_Cleaned.csv` — cleaned dataset
- `WA_Fn-UseC_-HR-Employee-Attrition.csv` — original dataset

## Workflow
1. Loaded and inspected the employee dataset.
2. Checked for missing values and duplicate records.
3. Cleaned and prepared the data.
4. Analyzed attrition across workforce categories.
5. Used SQL queries to calculate attrition metrics.
6. Developed a Power BI dashboard to communicate insights.

## Key Learnings
- Data cleaning and preprocessing
- Exploratory data analysis
- SQL aggregation and grouping
- HR analytics and KPI analysis
- Dashboard development and data storytelling

## How to Explore
Open the Jupyter Notebook to review the Python analysis, inspect the SQL file for queries, and open the Power BI file in Power BI Desktop to explore the dashboard.

## Data Source
The project uses the IBM HR Analytics Employee Attrition dataset. Refer to the dataset's original source and licensing terms when redistributing it.
